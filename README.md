# 마노스 위챗 발주 번역기 (1단계)

위챗 PC 옆에 붙어서 중국 업체와의 대화를 번역해 주는 세로 패널입니다.

## 하는 일
- **받는 메시지 (할 일 0번)**: 위챗 화면에 보이는 업체 메시지를 자동으로 읽어서, 한국어 번역과 **숨은 뜻**(완곡한 거절, 재촉, 불만 등)을 보여 줍니다.
- **보내는 메시지 (할 일 4번)**: 패널에 한국어 입력 + Enter → 중국어 번역이 자동 복사됨 → 위챗 입력창 클릭 → Ctrl+V → Enter
- 거래처별 대화 기록 저장, 말투 선택(정중/단호/친근), 자주 쓰는 문장 버튼
- 보조 기능: 업체 중국어를 Ctrl+C 하면 자동 번역 (자동 읽기가 놓친 경우)

## 안전 원칙
- 위챗 프로그램 내부(데이터, 메모리)에 접근하지 않습니다.
- 위챗에 입력하거나 클릭하거나 전송하지 않습니다. 화면에 보이는 그림만 읽습니다.
- 위챗이 맨 앞에 있을 때만 화면을 읽습니다.

## 저장 위치
`%APPDATA%\ManosWeChatTranslator` (설정, API 키, 대화 기록, 내 지시문 `instructions.txt`)

## 개발자용
```bash
pip install -r requirements.txt pytest
python -m pytest -q
python run.py
```
윈도우 실행 파일은 GitHub Actions의 **Build Windows exe** 워크플로를 수동 실행하면 만들어집니다.
